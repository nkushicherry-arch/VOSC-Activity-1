# VOSC Activity-1

## Tic-Tac-Toe Game

A colorful multi-board Tic-Tac-Toe game built using HTML, CSS, and JavaScript for VOSC Activity-1.

## Features

- 9 individual Tic-Tac-Toe boards
- Two-player gameplay
- X and O turns
- Multiple accessible boards
- Completed boards are claimed by X or O
- Three claimed boards in a row wins the match
- Winner highlighting
- Score tracking
- Restart option
- Responsive and colorful UI

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Select an available square on one of the accessible boards.
2. Players take turns placing X and O.
3. Complete a small board to claim it.
4. Get three claimed boards in a row to win the match.
5. Use the restart option to start a new match.

## How to Run

Open `index.html` in a web browser.

No installation or additional dependencies are required.
